# Hey 夥伴！請聽我說～～

> 工作上的大小事，都值得被聽見。
> 有想法、有建議、有點卡，還是真的有點受不了——都來說說看。

公司內部的即時反饋小系統。前台讓同事輕鬆留言（預設匿名），後台用標籤、涉及對象做分類與彙整，
慢慢看出哪些是單一事件、哪些問題重複發生、哪些人或流程出現共同的合作反饋。

架構與安全設計沿用大研訂購系統：React + TypeScript 前端部署在 GitHub Pages，
Google Apps Script + Google Sheets 當後端。

## 功能

**前台（同仁）**
- 五大類別：工作環境／工作流程／團隊夥伴／更上一層樓／我受不了了
- 「你希望我們怎麼回應？」四種選項；選「專人回覆」或「面對面聊聊」時才需要留下稱呼與聯絡方式
- 預設匿名；送出後拿到一組 12 碼**查詢碼**，可隨時查看處理狀態與後台的回覆
- 四種有人味的狀態：📮 訊息已經反映成功／🌱 種子已種下，我們等待發芽／🧠 有難度！燒腦中…／⚡ 即刻啟動處理

**後台（管理員）**
- 📥 收件匣：依類別、狀態、回應期待、標籤、涉及對象篩選與搜尋；改狀態、貼標籤、填涉及對象、寫給同仁的回覆、內部備註、結案
- 📊 彙整洞察：類別分佈、狀態與回應期待比例、標籤熱度（標示跨月「反覆出現」）、涉及對象（標示「共同反饋」）、近 6 個月趨勢、需要關心清單
- ⚙️ 設定：開放／暫停收件、前台公告、新回饋通知信箱
- 新回饋自動寄信通知；面談需求或「受不了」類別主旨會標【需要關注】
- 同仁留 Email 時，可在更新狀態／回覆時寄信通知對方

## 安全設計

| 項目 | 做法 |
|------|------|
| 外人送出 | 需要 `WRITE_TOKEN`（前端）+ `TEAM_CODE` 同仁通關密語（口頭告知同事） |
| 匿名 | Apps Script 以擁有者身分執行，拿不到送出者帳號或 IP；不留名就無從得知是誰 |
| 查詢碼 | 伺服器用安全亂數產生，只回傳一次；試算表只存 SHA-256 雜湊 |
| 查詢內容 | 用查詢碼只看得到自己寫的內容、狀態、對外回覆；看不到標籤、涉及對象、內部備註 |
| 管理員 | `ADMIN_PW` 驗證，錯 10 次鎖 15 分鐘；密碼只存在記憶體 |
| 機密不進網址 | 密碼、通關密語、查詢碼全部走 POST body |
| 防灌爆 | 全站 10 分鐘最多 40 則；通關密語錯 50 次、查詢碼錯 100 次暫時鎖住 |
| 併發 | 所有寫入在 `LockService` 內排隊；後台編輯以 `rev` 樂觀鎖定，不會互相覆蓋 |
| 重送 | 送出帶 `submissionId`，網路斷線時用它取回查詢碼，絕不自動重送 |
| 輸入 | 類別／回應／狀態白名單、長度上限、移除控制字元；Email 內容一律 escape |
| 頁面 | CSP、`noindex`、`no-referrer` |

## 部署步驟

1. **建立試算表**：新增一個 Google 試算表，複製網址中的 ID。
2. **建立 Apps Script**：試算表選單「擴充功能 → Apps Script」，把 `gas/Code.gs` 整份貼上，
   把開頭的 `SPREADSHEET_ID`、`SITE_URL` 改成你的值。
3. **設定指令碼屬性**（專案設定 ⚙️ → 指令碼屬性）：
   - `WRITE_TOKEN`：一串隨機字元
   - `TEAM_CODE`：同仁通關密語
   - `ADMIN_PW`：管理員密碼（12 字元以上）
4. 在編輯器執行一次 `checkSetup`（會要求授權 Sheets 與 Gmail），確認三項都「已設定」。
5. **部署**：「部署 → 新增部署作業 → 網頁應用程式」，執行身分「我」、存取權「任何人」，複製網址。
6. **前端**：建立獨立 GitHub repo（例如 `hey-partner`），把本資料夾內容放到 repo 根目錄，
   在 Settings → Secrets 設定 `REACT_APP_GAS_URL`、`REACT_APP_WRITE_TOKEN`，
   Settings → Pages 的 Source 選「GitHub Actions」，push 到 `main` 就會自動部署。
7. 打開網站 → ⚙️ 後台登入 → 設定通知信箱。

修改 `gas/Code.gs` 後，要到「部署 → 管理部署作業」部署新版本才會生效。

## 本機開發

```bash
cp .env.example .env.local   # 填入 GAS 網址與 token
npm install --legacy-peer-deps
npm start
```

```bash
npx react-scripts test --watchAll=false   # 測試
npm run lint                              # ESLint
```

## 試算表結構

| 工作表 | 用途 |
|--------|------|
| `feedback_data` | 機器用，每列一則：id／查詢碼雜湊／建立時間／JSON |
| `回饋總表` | 人看的鏡像表，每次寫入後自動重建（請勿手動編輯，改了會被覆蓋） |
| `app_config` | 前台設定（開放狀態、公告、通知信箱） |

Apps Script 編輯器可手動執行：`checkSetup`（檢查設定）、`resetLocks`（解除鎖定）、`rebuildViewSheet`（重建回饋總表）。
